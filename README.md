# Verify Before Actuate — research artifact

Code, archived results, and proofs for *Verify Before Actuate:
Risk–Latency-Aware Validation of Agentic Network Plans*.

An LLM agent turns an operator intent into a multi-step network change. This
artifact gates that plan: it freezes one execution order, verifies it at a
chosen depth, returns a counterexample when it rejects, and actuates only
what passes. The paper's question is not whether to verify but **how deep**,
given that deeper checking costs twice — the check itself, and the repair
rounds it triggers.

## Reproducing

Two kinds of claim, with different reproduction costs.

**Rescoring (no GPU, no model, minutes).** Every statistical claim is
recomputed from the archived generations. These are deterministic: identical
code over identical archived generations must reproduce every count exactly,
and a release replay verified 4,419 fields do.

```bash
cd pilot
uv sync                                  # z3-solver 5.0.0.0, Python >=3.12
PYTHONPATH=. uv run python run_analyze.py out/corpus_v2
PYTHONPATH=. uv run python run_selection.py --corpus out/corpus_v2
PYTHONPATH=. uv run python run_freeze.py --out ../paper/numbers.json
```

**Timing (hours).** Cost curves are wall-clock measurements and will *not*
reproduce to the digit — absolute verification times moved by up to a third
between two sweeps on the same machine. This is why the paper states timing
conclusions as shapes, ratios, and orderings, and reports the selection
rule's answer under both sweeps. Reproducing the *ordering* is the
meaningful check, not the milliseconds.

**Regenerating the corpus (needs the agent).** The 500 generations were
collected once against `qwen2.5:7b-instruct-q8_0` served locally by Ollama at
temperature 0.7. What pins them is the stored prompt hash, seed, sampling
parameters, and raw response — not the ability to re-emit them. Seeds are
derived by SHA-256 from cell identity and the master seed, so they do not
depend on interpreter or scheduling state.

## Topology data is not redistributed here

The 26 network instances come from **SNDlib** (Orlowski, Wessäly, Pióro,
Tomaszewski, *Networks* 55(3):276–286, 2010). SNDlib sets its own terms of
use, so this repository does not vendor the dataset. Fetch it yourself:

```bash
cd pilot && python fetch_sndlib.py     # downloads, verifies SHA-256, extracts
```

Expected archive SHA-256:
`14b59d9c0d00d566b21c29d845a0199eee25dbaae536f7b853c1cbb50863797b`

Node sets, adjacency, installed capacities, and demand matrices are read from
the dataset. Link latency is computed from the published coordinates. VNF
slot counts, processing delay, SLA bounds, priority flags, and ACL rules have
no SNDlib counterpart and are generated from a fixed seed — the loader
records, per field, whether a value was read, derived, or synthesized.

## What this artifact does not establish

Stated plainly, because the code is easy to over-read:

- **Not a live network.** The executor is an in-memory deterministic clone.
  "Actuate" never touches equipment.
- **Not an independent twin.** The twin backend shares transition and
  predicate code with the reference checker, so its agreement is largely by
  construction. It is a cost-curve generator, not a second opinion.
- **Not a formal proof of the implementation.** The SMT path binds concrete
  execution values into Z3 rather than symbolically encoding transitions. Its
  conformance test is a regression check against the reference semantics.
- **Not general network safety.** Only three predicate classes are encoded:
  resource, SLA, configuration integrity.

Section VII of the paper carries the full list.

## How this repository relates to the paper repository

This is a curated export, generated by `tools/sync_artifact.py` in the paper
repository, not a mirror of it. Excluded: the manuscript source (unsubmitted,
placeholder author block — only the frozen table travels), the SNDlib dataset
(fetched, see above), internal planning and literature notes, and
derivation-era theory notes written against an earlier notation. The
`commit_sha` recorded in archived result metadata refers to the paper
repository and will not resolve here.
